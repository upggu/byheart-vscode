# Sources for the built-in "Quotes" book

Public-domain criteria (design 5.4): the author died before 1955 **and** the text was published before 1930. Every sentence was checked verbatim against the Project Gutenberg plain-text edition linked below (2026-11-09); excerpts keep the source wording; only `--` became an em dash, a leading "But, " or a sentence-initial lowercase/uppercase word was adjusted to start the excerpt, and a trailing comma/dash became a period. Korean translations in the `.byheart.json` files were written for this project and are MIT-licensed like the rest of the code.
